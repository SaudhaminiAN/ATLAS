# Spec 15 — AI Explanation

## Objective

Natural-language explanations of finalized decisions. Read-only.

## Scope

### In Scope

- `IExplanationProvider` port
- Prompt from journal snapshot
- Persist to `decision_explanations`
- Rate limiting

### Out of Scope

- Signals, overrides, streaming, predictions

## Phase Note

**Phase 3.** MVP uses JSON in UI (Spec 21).

## Inputs

| Input | Source | Required |
|-------|--------|----------|
| `TradingDecision` + snapshots | `decisions` table | Yes |
| System prompt template | Config | Yes |

## Outputs

| Output | Type | Consumers |
|--------|------|-----------|
| `DecisionExplanation` | Domain model | Frontend (21) |
| Stored row | `decision_explanations` | REST |

## Interfaces

```python
class IExplanationProvider(Protocol):
    async def generate(self, prompt: str, max_tokens: int) -> str: ...

class AIExplanationServiceProtocol(Protocol):
    async def explain(self, decision_id: UUID) -> DecisionExplanation: ...
    def build_prompt(self, decision: TradingDecision) -> str: ...
```

## Database

| Table / Cache | Operation | Owner |
|---------------|-----------|-------|
| `decision_explanations` | INSERT (1 per decision) | This spec |

## Prompt Input Schema

```json
{
  "direction": "WAIT",
  "reason": "Validation failed",
  "confluence_score": 0.62,
  "evidence": [{"source": "smc_structure", "score": 0.7, "direction": "BUY"}],
  "failed_rules": ["minimum_rr_potential"],
  "news_blocked": false,
  "risk": null
}
```

Built from `decisions` snapshot only — no live re-fetch.

## Edge Cases

| Case | Behavior |
|------|----------|
| LLM timeout/failure | Log error; decision valid without explanation |
| Duplicate explain request | Return existing row |
| WAIT decision | Must cite specific blocking rule/threshold |

## Acceptance Criteria

- [ ] Prompt from snapshot only
- [ ] Guardrails in system prompt (unit tested)
- [ ] Mock provider in CI
- [ ] LLM failure non-blocking
- [ ] WAIT explanations specific
